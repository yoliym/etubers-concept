# Etubers Concept Website

A modern, responsive front-end concept created for Etubers, an Ethiopian digital-education platform focused on practical skills, free learning resources and guided mentorship.

> This is an independent portfolio concept created to demonstrate front-end design and development. It is not the official Etubers website and is not presented as an official partnership.

## Overview

The project was designed to transform Etubers’ practical, action-oriented educational identity into a premium editorial website experience.

The design uses:
- Real Etubers course thumbnails
- A dark editorial interface
- Etubers-orange accents
- Responsive layouts
- Clear learning paths
- Accessible navigation
- Verified official resource links

## Key Features

- Responsive desktop, tablet and mobile layouts
- Fixed navigation with active-section highlighting
- Hero section with clear learning and mentorship actions
- About and creator-authority section
- Practical programs gallery
- Learn → Build → Execute journey
- Official YouTube resource showcase
- Accessible FAQ accordion
- Final call-to-action section
- Verified external Etubers links
- GitHub Pages deployment through GitHub Actions
- Basic SEO and social-sharing metadata
- Custom favicon
- Reduced-motion and keyboard-accessibility support

## Run Locally

```bash
git clone https://github.com/yoliym/etubers-concept.git
cd etubers-concept
npm install
npm run dev
```

Vite will display the local development URL in the terminal.

## Production Build

```bash
npm run build
npm run preview
```

## Deployment

The website is deployed through GitHub Actions. Pushes to the `main` branch trigger a production build. The generated `dist` output is automatically deployed to GitHub Pages. The `dist` folder is not stored manually in the repository.

## Design Approach

The website uses one consistent editorial visual system. Real creator and course imagery gives it authenticity. Large serif headlines establish authority, while monospace labels and orange structural lines reinforce the action-focused identity. The page naturally guides visitors from free learning resources to formal mentorship.
